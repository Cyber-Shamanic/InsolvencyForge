# מדריך גיבוי ושחזור

1. היכנסו אל **מסמכים** ובחרו **DocumentVault — גיבוי ושחזור**.
2. בחרו **הורד גיבוי מוצפן**. הגדירו סיסמה חזקה של 12 תווים לפחות ואמתו אותה.
3. שמרו את קובץ `.ivault` בשני מקומות נפרדים. שמרו את הסיסמה בנפרד מהקובץ.
4. לשחזור בחרו **שחזר מקובץ**, בחרו את קובץ הגיבוי, הזינו סיסמה ואשרו החלפת רשימות.
5. בדקו לאחר שחזור שהקבצים נפתחים, שההערות קיימות ושהצ׳ק ליסט תקין.

**חלופה לא מוצפנת:** ייצוא `.zip` מתאים להעברה מקומית בסביבה מהימנה; הוא אינו מיועד לשיתוף מסמכים רגישים ללא הגנה.

**הבהרה:** ייצוא JSON הישן מגבה רק רשימות ושיחות, לא את תוכן הקבצים. יש להשתמש בגיבוי המלא החדש.
