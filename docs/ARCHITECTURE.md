# מבנה המאגר

- `README.md`, `CHANGELOG.md`, `TODO.md` — מסמכי שורש.
- `index.html`, `documents-v002.js`, `document-vault-v003.js` — קובצי אתר בשורש, להפעלה מקומית.
- `assets/` — גרפיקות מקוריות של האתר.
- `dist/` — עותק הפרסום העצמאי של האתר, המשמש את Sites.
- `docs/` — מדריכי אבטחה, גיבוי וארכיטקטורה.
- `.openai/hosting.json` — זיהוי ותצורת פרסום אתר קיים.

## v0.0.4 — הגשה מוגנת

- `web/` — מקורות הדפים, הסקריפטים והנכסים הנארזים בשרת.
- `worker/index.js` — שער סיסמה והגשת נכסים לאחר אימות.
- `scripts/build-worker.mjs` — אורז את נכסי האתר לתוך Worker עצמאי.
- `dist/server/index.js` — תוצר בנייה בלבד, אינו מקור לעריכה.
- משתנה זמן ריצה סודי בשם `ACCESS_PASSWORD` נדרש לפרסום. ערכו אינו שמור במאגר.

המערכת פועלת ללא שרת אפליקטיבי. קובצי האתר נטענים מקומית והמידע נשמר בדפדפן. ממשק DocumentVault משתמש בממשקי Web Crypto ו־IndexedDB מובנים, ללא ספריות צד שלישי בזמן ריצה.
