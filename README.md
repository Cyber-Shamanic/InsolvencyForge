# InsolvencyForge

ממשק ניהול אישי לתהליך חדלות פירעון, v0.0.4.

הפעלת האתר: פתחו את `dist/index.html` בדפדפן מודרני. עיצוב RTL, HTML/CSS/JavaScript ללא תלות חיצונית.

חשוב: מידע משימות ורשימות נשמר ב־localStorage וקבצים ב־IndexedDB במכשיר. גרסה 0.0.2 מוסיפה חיפוש, סינון, תיוג, שיוך לצ׳ק ליסט והדפסת אינדקס. גרסה 0.0.3 מוסיפה ZIP מלא ו־IVAULT מוצפן בצד הלקוח, שחזור מקומי והיסטוריית גרסאות בסיסית. גרסה 0.0.4 מוסיפה כניסה מוגנת בצד השרת והעדפות נגישות. אין אחסון נתונים מוצפן בצד שרת, חשבונות משתמשים נפרדים, או מודל AI אמיתי. גיבוי JSON הישן אינו כולל קבצים; השתמש בגיבוי DocumentVault כדי לכלול אותם. אין להסתמך על אחסון הדפדפן כגיבוי יחיד למסמכים חיוניים.
